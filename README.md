# Requirements-Based Testing Project – Online Cinema Booking System

## Project Overview

This project demonstrates requirements-based testing for an Online Cinema Booking System.

The goal of the project was to analyse business requirements, identify requirement gaps, create test scenarios, and design test cases based on user stories and acceptance criteria.

---

## Project Scope

The project covers:

- Requirements analysis
- User stories review
- Acceptance criteria review
- Questions for Business Analyst (BA)
- Test scenarios creation
- Test case design
- Additional test ideas

---

## Tested Features

- Book a cinema ticket
- Choose a seat
- Receive booking confirmation
- View available movies

---

## Skills Demonstrated

- Requirements-Based Testing
- Requirements Analysis
- Test Design
- Test Scenario Creation
- Test Case Design
- Critical Thinking
- Defect Prevention Through Requirement Review
